# Poring Fix - ชุดพร้อมใช้งาน

มี 2 ส่วน:
1. `web/` เว็บไซต์ + PWA
2. `android/` แอป Android WebView

ลำดับการใช้งาน:
1. นำ `web/` ไปโฮสต์บน HTTPS
2. จด URL ที่ได้
3. เปลี่ยน URL ใน MainActivity.java
4. เปิด `android/` ด้วย Android Studio
5. สร้าง Signed APK

หมายเหตุ: ผมไม่สามารถเผยแพร่เว็บเข้า account ของคุณหรือเซ็น APK ด้วย keystore ของคุณแทนได้จากแชตนี้
